# My Portfolio

APDEVET Midterm Exam: a Flutter app with five tabs (Personal, Education,
Skills, Interests, Contact).

## Structure

```
lib/
  main.dart            app entry + TabBar / TabBarView
  app_theme.dart       shared colors, typography, spacing
  screens/             one file per tab
assets/images/         put profile.jpg here
```

## Run

```
flutter pub get
flutter run -d chrome
```
